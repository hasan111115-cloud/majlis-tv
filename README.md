# مجلس | MAJLIS

واجهة تلفزيون ذكي للبيت والمجلس: بث مباشر، ساعة، تاريخ ميلادي وهجري، مواقيت الصلاة، والطقس — في شاشة واحدة.

## التشغيل السريع

مجلد `dist` هو الموقع الجاهز. ارفعه كما هو إلى أي استضافة ثابتة:

- **Netlify Drop**: افتح app.netlify.com/drop واسحب مجلد `dist` إليه، تحصل على رابط فورًا.
- **GitHub Pages / Vercel / Cloudflare Pages**: ارفع محتوى `dist`.
- **على جهاز في البيت** (يتيح بث هيئة الإذاعة بجودة 720p، انظر «ملاحظة http» تحت):
  ```
  cd dist
  python3 -m http.server 8080
  ```
  ثم افتح `http://عنوان-الجهاز:8080` من متصفح التلفزيون.

## التشغيل التلقائي لقناة السنة

تبدأ قناة السنة النبوية تلقائيًا فور فتح الصفحة بدون أي ضغطة.

- يحاول المشغّل التشغيل بالصوت أولًا.
- إذا منع المتصفح الصوت التلقائي (سياسة في كل المتصفحات الحديثة)، يبدأ البث فورًا بلا صوت، ويعود الصوت مع **أول ضغطة على أي زر** في الريموت أو لمسة في أي مكان.
- لجعل الصوت يبدأ من أول لحظة بدون أي ضغطة:
  - **Chrome**: ثبّت الموقع كتطبيق (Install) من شريط العنوان، أو من إعدادات الموقع اجعل «الصوت» على «سماح». كما يتذكّر Chrome المواقع التي تشغّل فيها الصوت كثيرًا ويسمح لها تلقائيًا مع الوقت.
  - **Safari على Mac**: Safari ← إعدادات هذا الموقع ← التشغيل التلقائي ← «السماح بكل التشغيل التلقائي».
  - **جهاز مخصّص للعرض (Kiosk)**: شغّل Chrome بالخيار `--autoplay-policy=no-user-gesture-required`.

## القنوات

الروابط في `dist/channels.json` (والأصل في `public/channels.json`). عدّلها بأي محرر نصوص دون إعادة البناء:

```json
{ "id": "sunnah", "name": "قناة السنة النبوية", "short": "السنة",
  "officialUrl": "https://www.sba.sa/", "logo": "",
  "sources": [ { "label": "…", "url": "https://…/playlist.m3u8" } ] }
```

- كل قناة تقبل أكثر من مصدر؛ يجرّبها المشغّل بالترتيب ويتحوّل للبديل تلقائيًا عند الفشل.
- `logo`: ضع رابط الشعار الرسمي إن كان لديك إذن باستخدامه، وإلا تظهر لوحة باسم القناة.
- من داخل الموقع (الإعدادات ← القنوات) تقدر تحذف أي قناة، تعدّل روابطها، ترتّبها، تضيف قناة جديدة، أو تستعيد القنوات الأصلية. يُفحص الرابط قبل الحفظ ويوضح سبب المشكلة إن لم يعمل.
- الروابط المقبولة: m3u8، أو رابط بث يوتيوب (watch?v= أو /live/ أو youtube.com/channel/UC…). روابط صفحات المواقع ورابط اسم قناة يوتيوب (@…) لا تعمل.
- جودة البث: «تلقائية» تبدأ بأعلى جودة ثم تتكيّف مع سرعة الإنترنت، و«أعلى جودة دائمًا» تثبّتها. الجودة الحالية تظهر أعلى المشغّل.

**المصادر الحالية** مأخوذة من خوادم الجهات نفسها (هيئة الإذاعة والتلفزيون live.net.sa، وشاهد) ومن Globecast موزّع بث الهيئة. هذه الروابط قد تتغيّر أو تُقيَّد جغرافيًا؛ إن توقفت قناة يظهر تنبيه مع زر «إعادة المحاولة» و«الموقع الرسمي».

**ملاحظة http**: بث هيئة الإذاعة بجودة 720p متاح عبر `http` فقط. المتصفحات تمنع روابط http داخل موقع https، فعند الاستضافة على https يستخدم المشغّل تلقائيًا مصدر Globecast (https، بجودة 360p). للحصول على 720p شغّل الموقع عبر http على جهاز في البيت كما في الأعلى.

## البيانات الحية

| البيانات | المصدر | يحتاج مفتاح؟ |
|---|---|---|
| مواقيت الصلاة | حساب فلكي على الجهاز بمكتبة adhan، طريقة أم القرى افتراضيًا (مع +٣٠ دقيقة للعشاء في رمضان) | لا، ويعمل بدون إنترنت |
| التاريخ الهجري | تقويم أم القرى المدمج في المتصفح، مع تعديل ±يوم من الإعدادات | لا |
| الطقس والتوقعات | Open-Meteo، يُحدَّث كل ١٥ دقيقة (~١٠٠ طلب يوميًا، ضمن الحد المجاني لغير التجاري) | لا |
| البحث عن مدينة | Open-Meteo Geocoding | لا |
| اسم المدينة من الموقع الجغرافي | BigDataCloud (واجهة المتصفح المجانية) | لا |

لا توجد مفاتيح سرية في الكود، ولا يحتاج الموقع خادمًا وسيطًا.

## التطوير

```
npm install
npm run dev      # تطوير
npm run build    # يبني مجلد dist
npm run preview  # معاينة النسخة المبنية
```

البنية: `src/components` (Header, Clock, DateDisplay, LivePlayer, ChannelList, PrayerTimes, WeatherWidget, WeatherPanel/WeatherForecast, SettingsPanel)، و`src/lib` (الإعدادات، الوقت، المواقيت، الطقس، الموقع، التنقل بالريموت).

## ما تم اختباره

في Chrome حقيقي على شاشة 1920×1080 وشاشة هاتف، باستخدام بث HLS تجريبي محلي محل روابط القنوات:
تشغيل قناة السنة تلقائيًا خلال ~١.٥ ثانية بلا ضغطة، والتحول للتشغيل بلا صوت عند منع المتصفح ثم عودة الصوت مع أول زر، والتبديل بين القنوات بالأرقام، وظهور رسالة الخطأ مع إعادة المحاولة عند تعذّر قناة، والتنقل بالأسهم، ولوحة الطقس، وحفظ الإعدادات واستعادة آخر قناة بعد إعادة التحميل، و٣٠ تبديلًا متتاليًا للقنوات بلا تسرّب ذاكرة، واستمرار الساعة والبث في وضع العرض المستمر.

لم يكن ممكنًا الوصول إلى خوادم البث الحقيقية من بيئة الاختبار، لذلك جرّب القنوات على جهازك أول مرة.

إبقاء الشاشة مضاءة يُطلب عبر Wake Lock حيث يدعمه المتصفح؛ إن لم يُدعم، اضبط مهلة إطفاء الشاشة من إعدادات الجهاز. حالة الدعم تظهر في الإعدادات ← العرض.
